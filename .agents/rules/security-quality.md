# 安全性與品質規範

- 私人 API 及 RLS 獨立檢查家人資格；管理寫入同時檢查角色。保留同源寫入限制、HttpOnly 會話和私人回應不快取。
- 登入委由 Supabase Auth；不得自行儲存密碼或把 Token、上傳密鑰、憑證、家族資料寫入日誌或版本控制。
- 驗證請求大小、結構及日期；使用參數化查詢與既有資料驗證。上傳以實際位元組和解碼後尺寸驗證，不信任副檔名或 MIME 標示。
- 前端禁止使用 `dangerouslySetInnerHTML`；瀏覽器只呼叫同源 API，私人照片不得透過共用代理或公開簽名網址。
- 驗證錯誤、角色差異、撤權與還原。CI 未通過不得合併。雲端驗收只能用獨立環境及假資料，待備份驗證後才切正式站。
