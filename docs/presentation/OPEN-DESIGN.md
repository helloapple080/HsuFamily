# 簡報 Open Design 規格

本簡報以 GitHub Primer 的開源產品語彙為靈感，採 MIT 授權隨專案公開，可自由編輯與再利用。

## 設計目標

- 長官可在 10 分鐘內理解「做了什麼、風險降低多少、還要決定什麼」。
- 每頁只承擔一個管理訊息，技術名詞旁附可理解的管理意義。
- 內容採 PowerPoint 原生可編輯文字與圖形，不把重要資訊烘焙成不可修改圖片。

## 視覺系統

| Token | 色碼 | 用途 |
|---|---|---|
| Ink | `#0D1117` | 主文字／封面 |
| Canvas | `#FFFFFF` | 背景 |
| Soft | `#F6F8FA` | 資訊區塊 |
| Line | `#D0D7DE` | 分隔線 |
| Green | `#1F883D` | 已完成／正向控制 |
| Blue | `#0969DA` | 驗證／技術證據 |
| Amber | `#BF8700` | 待驗收／注意 |
| Red | `#CF222E` | 原始高風險／上線閘門 |

字體優先使用 PingFang TC；標題至少 48 px、內文至少 18–22 px。版面為 16:9（1280 × 720）。

## 敘事結構

1. 管理結論。
2. 架構證據。
3. 高風險修復。
4. 登入安全與部署安全。
5. CI 驗證證據。
6. 剩餘責任、路線圖與決策。

## 使用與修改

簡報檔 `HsuFamily-Enterprise-Readiness.pptx` 可直接以 PowerPoint、Keynote 或 LibreOffice Impress 開啟。修改時應保留「已完成／待環境驗收」的邊界，避免把程式碼控制誤寫成完整企業上線認證。
