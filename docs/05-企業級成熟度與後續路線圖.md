# 企業級成熟度與後續路線圖

> **2026-07-24 狀態更新：** 最新依賴掃描已出現 High release blockers，故目前仍可判定「具企業級思維」，但不可判定「正式上線就緒」。完整證據請見 [Skills 全面自檢報告](./07-Skills全面自檢報告.md)。

## 評估定義

企業級不是單一框架或「沒有漏洞」，而是可追溯的架構決策、預設安全、可重現部署、自動品質閘門，以及有人負責的持續治理。

## 目前成熟度

| 能力 | 判定 | 說明 |
|---|---|---|
| 現代技術與分層架構 | 良好 | .NET 10、Next.js 16、TypeScript strict、Clean Architecture 邊界 |
| 身分與存取控制 | 良好 | 預設授權、RBAC、Argon2id、Cookie session、rotation |
| 應用安全 | 良好 | CSRF、CORS allowlist、rate limit、安全 headers、安全例外 |
| 資料與容器安全 | 良好 | Mongo 最小權限、非 root、key persistence、固定版本 |
| 自動化品質 | 基礎良好 | 前後端 CI 與安全整合測試；仍應提高 coverage 與 E2E |
| 可觀測性 | 待建置 | 尚未接入正式 metrics、traces、central logs、alerts |
| 營運韌性 | 待驗證 | 尚未取得備份還原、災難復原、容量與壓力測試證據 |
| 組織治理 | 待制度化 | 需 code owners、PR review、弱點 SLA、事故演練與存取審查 |

## 分階段路線圖

### P0：上線閘門

- Next.js／Axios／.NET security patch 升級，dependency audit 無未接受的 High。
- CI 加入 dependency、CodeQL、container scan 與 SBOM gate。
- TLS、HSTS、正式 hosts／origins／proxy allowlist。
- Secret Manager 與 secrets 輪替。
- Mongo 備份還原演練。
- 正式監控、告警、集中日誌與值班責任。

### P1：一個迭代內

- Playwright login → refresh → logout 真實 E2E。
- Auth 流程移至 Application Service，降低 Controller 複雜度。
- Dependabot／Renovate、CodeQL、container image scan、SBOM。
- PR branch protection、至少一位 reviewer、CODEOWNERS。

### P2：持續成熟

- CSP nonce，移除 inline 放寬。
- 壓力測試與容量基準。
- SLO／錯誤預算、RPO／RTO 與災難演練。
- 年度威脅建模與第三方滲透測試。

## 管理決策建議

允許專案進入「受控試營運／正式環境建置」階段，但上線核准應以 P0 證據為條件。程式碼基線已具備企業級思維；後續投資應集中在營運、可觀測性、供應鏈與治理，而非再次重寫技術棧。
