# 安全風險與修復台帳

## 台帳判定

截至 `57d1110`：

- 程式碼／直接部署範本層的已知 Critical：`0` 個 open。
- 程式碼／直接部署範本層的已知 High：`0` 個 open。
- pnpm production audit：Critical `0`、High `0`、Low `1`。
- 正式生產環境認證：尚未完成，因此環境與治理風險仍為 open。

舊版文件中的供應鏈／production deployment release-blocker 敘事已過期。Next.js、Axios 與 production compose 均已修復並納入回歸 gate；不得再把它們列為 open。

## 接受中的技術取捨

- Framer Motion／部分元件需要 runtime style attributes，因此 CSP 暫保留 `style-src-attr 'unsafe-inline'`；`script-src` 不放寬。
- Nonce CSP 使 root layout 動態 rendering；以安全換取部分靜態快取效能，正式環境需容量監控。
- MongoDB 既有 documents 不因新 validation 被批次改寫；相容讀取與未來寫入限制並存。
- CI 的 `150` 是**最低測試數 gate**，不是 coverage 百分比門檻；coverage 目前以 artifact 留證，後續應依基準制定合理門檻。
