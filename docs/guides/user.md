# 許氏入口網使用者手冊

[瀏覽器版](user.html)

在管理員發出正式網址和新帳號指引前，請不要把家族資料或照片輸入測試站。

## 家人的日常操作

管理員會提供入口網網址和登入方式，不能自助註冊。[目前的 Cloudflare 隔離測試站](cloudflare-staging.md)只開放給持有人：按「Cloudflare」，使用原本的 Cloudflare 帳號，不會寄一次性登入碼，也不必另設網站密碼。家人請先維持使用原來的入口；若是舊版 Next.js，沿用原本的信箱和入口網密碼。

- 「行事曆」有兩種檢視。「拜拜日期」在 Cloudflare 私人入口會先顯示「下一次拜拜」，包含國曆、農曆，以及同一天的所有拜拜項目。想查別年時再改下方「國曆年份」；不會影響上方顯示的下一次日期。「活動月曆」則依月份顯示家族活動和國農曆日期。
- 管理員：選「新增規則」，設定每年固定農曆月日，或每個農曆月固定一日。也可選擇一般月份、只限閏月或兩者。沒有該日的農曆月份會略過，例如小月沒有三十。每年農曆八月十五的規則只要設定一次，切換到 2026 或 2036 都會自動換算（目前支援西元 1901–2100 年）。
- 「家庭成員」可看稱謂、生日及頭像；「歷年行程」可以搜尋標題、地點、簡介或標籤，再展開照片。
- 管理員先新增一筆紀錄，儲存後再打開「頭像」或「照片」上傳。頭像 1 張，行程和簡式拜拜規則各 5 張。支援 2 MiB 以下的靜態 JPEG、PNG 或 WebP；手機若存為 HEIC，請先轉成 JPEG。要刪除帶照片的紀錄，請先移除照片。
- 照片只讓核准家人查看，沒有公開分享網址。可從選單切換淺色、深色或跟隨系統。使用共用手機或電腦時，記得登出。
- 新版多人共用資料，更新後重新查詢；沒有即時推播。若提示別人改過這筆，先保留你的草稿，核對新內容後再存，不要直接覆蓋。

## 家用備忘：記錄設備與店務

這是 Cloudflare 私人入口的功能；公開展示與舊版入口不提供。新頁面從空白開始，不會自動載入範例或搬入其他資料。

1. 從導覽選「家用備忘」。管理員按「新增備忘」，選供水、店務、設備或其他，填標題、位置（選填）和說明後按「儲存」。例如水塔開關的位置和關閉步驟、濾水器型號與換芯方式、店的營業時間。說明最多 2,000 字，整區最多 200 筆，不支援附件。
2. 要記錄保養時，可填「上次處理日」和「下次到期日」，例如上次換濾芯的日子和下次要換的日子。兩欄都可留空；兩欄都有填時，到期日不得早於上次處理日。有到期日的備忘會排在上面，依台北日期標示「已逾期」、「今天到期」或「7 天內到期」。只在站內顯示，不寄信、不推播，也不會自動順延。
3. 家人可在「搜尋備忘」輸入關鍵字，也可用「篩選分類」縮小範圍。核准家人可查看全部備忘，只有管理員可編輯、刪除；刪除前會確認。多人同時編輯時，畫面會提示衝突並保留草稿。
4. 請勿記錄密碼、門鎖密碼、驗證碼或其他不應與全部家人共享的資訊。隔離站只做驗收，正式資料等管理員發出可用的私人正式網址再填。正式使用不需要先建立假資料。

## 用手機瀏覽

1. 用手機瀏覽器開管理員給的網址，不用安裝 App。登入後，直接從底部切換「行事曆」、「家庭成員」、「歷年行程」或 Cloudflare 私人入口的「家用備忘」。目前所在頁會高亮。要切換主題或登出，再點右上角「帳號與顯示設定」。
2. 切到「活動月曆」時，如果看不到最右邊的日期，在月曆格子裡左右滑；其他區塊維持正常上下捲動。
3. 手機的備忘表單從下方開啟，不會立即跳出鍵盤；需要填寫時再點欄位。表單內容可以上下滑，「取消」和「儲存」留在底部。其他功能的表單如果較長，可在視窗內上下滑。看不到新增或編輯按鈕時，可能是帳號只有查看權限。

Chrome 已用 320×568、390×844、568×320 模擬手機，驗證底部導覽與備忘表單。iPhone Safari 與 Android Chrome 的實機鍵盤、登入及選照片仍待驗收。隔離站不放真實照片或備忘，現階段也未開放照片上傳。

## 登入或資料顯示異常

- 測試站顯示無法登入時，確認選的是核准的 Cloudflare 帳號；其他帳號目前不能使用。舊版忘記密碼請找家族管理員。
- 資料未更新時先重新整理。仍有問題可回報網址、頁面與時間，不要附上密碼或私人照片。
- [公開展示](https://helloapple080.github.io/HsuFamily/) 可先熟悉介面，使用假資料，不能登入或儲存變更。
