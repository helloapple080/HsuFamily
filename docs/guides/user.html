家人使用 · 開發與部署

許氏入口網使用者手冊¶ ↑

瀏覽器版

目前精簡版正在開發，沒有切換正式網址或搬移家族資料。在管理員發出新網址和新帳號指引前，原有登入方式不變。

精簡版預覽：登入與拜拜行事曆¶ ↑

管理員會提供預覽網址和核准的電子信箱。使用該信箱和預覽帳號密碼登入，不需登入 Google，也不能自行註冊。請勿把正式家族資料或照片輸入預覽站。

  • 家人：在「行事曆」選擇西元年份，就能查看該年拜拜的國曆與農曆日期。

  • 管理員：選「新增規則」，設定每年固定農曆月日，或每個農曆月固定一日。也可選擇一般月份、只限閏月或兩者。沒有該日的農曆月份會略過，例如小月沒有三十。每年農曆八月十五的規則只要設定一次，切換到 2026 或 2036 都會自動換算。

  • 可從選單切換淺色、深色或跟隨系統。成員、行程、照片尚未加入精簡版。

以下為原版操作說明。

1. 第一次登入¶ ↑

向家族管理員取得正式網址和帳號。一般家人使用入口網帳號登入。Google Drive 設定由管理員處理，家人登入時只需要入口網帳號。

手機與電腦均可用瀏覽器開啟。使用完畢請從網站登出，尤其是共用裝置。忘記帳密時請找管理員。

2. 查看行事曆與拜拜日期¶ ↑

打開「行事曆」，使用上個月、下個月或「今天」切換。日期同時顯示國曆和農曆，家族的拜拜與活動會標記在對應日期。

管理員新增事件時，可勾選「使用農曆日期」，再設定「每年在相同農曆月日」或「每個農曆月在指定日期」。例如每年農曆八月十五拜拜，先選某一次對應的國曆日期，勾選農曆，再選每年重複。之後查看其他年份，系統會依設定換算該年的國曆日期。若該月遇到閏月，可在編輯時選擇一般月份、閏月或兩者。

3. 家庭成員與歷年行程¶ ↑

  • 「家庭成員」可查看稱謂、生日及成員介紹。管理員可新增、編輯或刪除成員。

  • 「歷年行程」可查看行程日期、地點與紀錄，也可以搜尋。管理員可新增、編輯或刪除行程。

  • 一般成員可瀏覽。需要更正內容時，請通知家族管理員。

4. 顯示主題¶ ↑

新版介面可在主題控制中選擇淺色、深色或跟隨裝置系統。不同裝置可以各自選擇。

5. 照片與公開範圍¶ ↑

目前照片上傳的基礎程式已開發，成員頭像、拜拜照片和行程相簿仍待接入各頁面。正式版完成驗收並開通後，再從對應紀錄上傳和查看。

私人照片應維持「僅限家人」。若未來選擇「公開」，持有圖片網址的人可能直接讀取。上傳前先確認照片內容和家人同意。

6. 網站打不開或資料沒更新¶ ↑

  • 網站出現登入頁時，重新登入再查看。如果帳密仍無法使用，請找管理員。

  • 行事曆更新較慢時，先重新整理網頁。若仍未顯示，記下日期和頁面告訴管理員。

  • 正式網址出現連線錯誤時，可將網址和出錯時間回報給管理員。
