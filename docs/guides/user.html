許氏入口網使用者手冊¶ ↑

瀏覽器版

在管理員發出正式網址和新帳號指引前，請不要把家族資料或照片輸入測試站。

家人的日常操作¶ ↑

管理員會提供入口網網址和登入方式，不能自助註冊。目前的 Cloudflare 隔離測試站只開放給持有人：按「Cloudflare」，使用原本的 Cloudflare 帳號，不會寄一次性登入碼，也不必另設網站密碼。家人請先維持使用原來的入口；若是舊版 Next.js，沿用原本的信箱和入口網密碼。

  • 「行事曆」有兩種檢視：「拜拜日期」依西元年份換算，「活動月曆」依月份顯示家族活動和國農曆日期。

  • 管理員：選「新增規則」，設定每年固定農曆月日，或每個農曆月固定一日。也可選擇一般月份、只限閏月或兩者。沒有該日的農曆月份會略過，例如小月沒有三十。每年農曆八月十五的規則只要設定一次，切換到 2026 或 2036 都會自動換算（目前支援西元 1901–2100 年）。

  • 「家庭成員」可看稱謂、生日及頭像；「歷年行程」可以搜尋標題、地點、簡介或標籤，再展開照片。

  • 管理員先新增一筆紀錄，儲存後再打開「頭像」或「照片」上傳。頭像 1 張，行程和簡式拜拜規則各 5 張。支援 2 MiB 以下的靜態 JPEG、PNG 或 WebP；手機若存為 HEIC，請先轉成 JPEG。要刪除帶照片的紀錄，請先移除照片。

  • 照片只讓核准家人查看，沒有公開分享網址。可從選單切換淺色、深色或跟隨系統。使用共用手機或電腦時，記得登出。

  • 新版多人共用資料，更新後重新查詢；沒有即時推播。若提示別人改過這筆，先保留你的草稿，核對新內容後再存，不要直接覆蓋。

用手機瀏覽¶ ↑

  1. 用手機瀏覽器開管理員給的網址，不用安裝 App。登入後，點右上角選單切換「行事曆」、「家庭成員」、「歷年行程」，也能在選單切主題或登出。

  2. 切到「活動月曆」時，如果看不到最右邊的日期，在月曆格子裡左右滑；其他區塊維持正常上下捲動。

  3. 新增或編輯資料的視窗太高時，在表單內向上滑，即可看到底部的「取消」、「儲存」等按鈕。看不到新增或編輯按鈕時，可能是帳號只有查看權限。

測試站已用瀏覽器模擬大小手機與橫放尺寸，實測導覽、月曆和表單。iPhone Safari 與 Android Chrome 的實機鍵盤、登入及選照片仍待驗收。先用假資料試操作，不要上傳真實照片。

登入或資料顯示異常¶ ↑

  • 測試站顯示無法登入時，確認選的是核准的 Cloudflare 帳號；其他帳號目前不能使用。舊版忘記密碼請找家族管理員。

  • 資料未更新時先重新整理。仍有問題可回報網址、頁面與時間，不要附上密碼或私人照片。

  • 公開展示 可先熟悉介面，使用假資料，不能登入或儲存變更。
