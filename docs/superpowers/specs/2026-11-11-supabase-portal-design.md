# 許氏入口網精簡版

原有 Next.js 16 畫面、主題、農曆套件保留。精簡版只需一個 Next.js 部署與一個 Supabase 專案；既有 .NET、MongoDB、Cloudflare Tunnel 和 GitHub Pages 繼續可用，直到正式切換。開發者與家人手冊隨各可用功能更新。

## 版本邊界

1. 底層：Supabase 登入使用者與家人名單分開。角色由管理者配置，不採信帳號自行修改的資料。用資料庫權限保護資料及私人照片。農曆規則儲存月日與閏月政策，跨年換算使用現有套件。
2. 接線：先讓登入、農曆規則的建立和讀取走新服務，再接成員、行程與照片。Server API／Action 驗證輸入，資料庫 RLS 獨立檢查存取。先移除常駐 SignalR 的需求，資料以重新查詢更新。
3. 搬遷：以唯讀方式匯出 MongoDB，驗證格式與文件數量，在隔離環境還原並對照；帳號重新核准，不複製既有密碼雜湊。照片須在授權後才可存取。原版保留到切換驗收後。

正式切換之前，匿名、未核准帳號和被撤權帳號皆不得讀取私人資料；已核准家人只讀，管理員可編輯。驗收涵蓋跨年、閏月、缺日、照片權限，以及備份還原。測試資料不含真實家人個資。
