# 家用備忘：設計與驗收

- **目的：** 家人在手機或桌面能快速找到供水開關、店務、設備與耗材資訊。獨立選單比行程備註好找，也不用另開服務或維護外掛。
- **版面：** 沿用私人入口的側欄、深淺色與同一套控件。先顯示搜尋與分類，再列最近更新的條目；每筆依序顯示標題、位置、分類、說明。管理員可就地新增、修改，並在確認後刪除。空白頁有建立入口，不植入樣本。
- **儲存：** Cloudflare D1 新增 `portal_household_notes`，不重寫既有資料表。分類「供水／店務／設備／其他」；標題 100、位置 120、說明 2000 字元；同一入口最多 200 筆。搜尋及分類在已驗證的清單中進行，不把搜尋字帶入網址或記錄。
- **邊界：** 只有核准的家人可讀，管理員限同源新增、編輯、刪除；修改及刪除須帶讀取時的版本，舊版本不會覆蓋新內容。說明只呈現純文字，回應不得共用快取，不用來保管密碼、PIN、門鎖碼或金鑰。公開展示及 Next.js/Supabase 回退版不提供此區。
- **發布：** 本機和 CI 驗證權限與 CRUD；隔離 D1 先備份、驗證還原，再套加法遷移和部署。正式站、既有假規則、Access 白名單與費用不變。正式使用前補真人帳號、手機與備份流程驗收，不把測試環境當正式資料庫。
