# 精簡版成員、行程與私人照片

**Goal:** 完成已核准的精簡版第二階段，補上家人日常使用的資料頁、私人照片，並為隔離環境準備搬遷驗收。

**Architecture:** 沿用現有介面與 Query hooks，精簡版切換到同源 API。資料驗證、資料庫及照片處理分層；管理權限在 API 和 RLS 各自檢查。照片不使用公開連結；既有 .NET、MongoDB 和展示版不受影響。

- [x] 驗證日期、輸入與搜尋邊界；接通成員／行程 CRUD、行程查詢、月曆事件與角色政策。
- [x] 驗證圖片實際內容、尺寸、權限及下載；成員、行程與拜拜規則可管理私人照片。
- [x] 以假資料驗證匯出轉換與匯入；不碰正式連線、帳密或照片。
- [x] 完成三種建置、測試與依賴掃描，更新開發者與使用者的 Markdown／HTML 手冊。
- [ ] 在明確指定的隔離雲端專案驗收。正式資料、帳號重建和網址切換另有驗收門檻。

## 本機驗收證據

- 前端 127 項測試、既有 .NET 353 項測試通過；前端 ESLint、CSP 規則檢查與正式依賴掃描通過。
- 精簡版、既有網站和 GitHub Pages 都能建置；確認公開靜態產物不包含私人 API。
- 以 Playwright 及本機模擬服務驗證登入、成員、頭像上傳／下載、淺色切換、行程、活動月曆與登出；登出後原照片網址回傳 401。
- 權限與離線匯入使用嵌入式 PostgreSQL 驗證。尚未使用託管 Auth／Storage，也未部署正式網址或搬移 MongoDB 資料。
